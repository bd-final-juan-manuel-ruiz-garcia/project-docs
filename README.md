# 🗺️ Proyecto Final - Sistema de Gestión de Glamping

Bienvenido al repositorio oficial de documentación del sistema de información y persistencia relacional para la gestión operativa y financiera de un Glamping de alta gama.

## 👥 Integrantes
* Juan Manuel Ruiz García

## 🚀 Componentes del Proyecto
El proyecto se encuentra estrictamente dividido en dos entornos independientes según los requerimientos de la entrega:

1. **📂 Repositorio de Código e Infraestructura (`project-bd`):** Contiene el despliegue contenerizado con Docker, la automatización del esquema con Liquibase (DDL) e inyección de datos masiva (DML). 
   👉 [Acceder al Repositorio de Código de Base de Datos](https://github.com/bd-final-juan-manuel-ruiz-garcia/project-bd)

2. **📖 Repositorio de Documentación (`project-docs`):** Contiene la especificación de requisitos, reglas de negocio, modelos conceptuales/lógicos/físicos, diccionario de datos completo y evidencias de ejecución.
   👉 [Acceder al Repositorio de Documentación (Usted está aquí)](https://github.com/bd-final-juan-manuel-ruiz-garcia/project-docs)
