# Modelo Conceptual

Entidades principales:  
- Huésped  
- Reserva  
- Habitación  
- Consumo  
- Pago  
- Caja  

Relaciones:  
- Un huésped puede tener varias reservas.  
- Una reserva corresponde a una habitación.  
- Un huésped puede generar múltiples consumos.  
- Un pago está asociado a una reserva.
