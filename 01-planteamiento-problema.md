# Planteamiento del Problema

El dominio seleccionado es **Sistema Hotelero**.  
El problema a representar es la gestión de huéspedes, reservas, habitaciones y consumos dentro de un hotel.  

Se busca modelar una base de datos que permita:  
- Registrar huéspedes y sus datos de contacto.  
- Gestionar reservas y asignación de habitaciones.  
- Registrar consumos en restaurante/bar.  
- Consolidar pagos y cierre de caja.  

Este planteamiento servirá como base para construir el modelo conceptual, lógico y físico.
