# Requerimientos del Proyecto

## Requerimientos funcionales
- Registrar huéspedes con datos personales y de contacto.  
- Gestionar reservas (crear, modificar, cancelar).  
- Asignar habitaciones disponibles.  
- Registrar consumos en restaurante y bar.  
- Consolidar pagos en el check-out.  
- Generar reportes de cierre de caja.  

## Requerimientos no funcionales
- Integridad referencial en todas las tablas.  
- Disponibilidad de la base de datos mediante Docker.  
- Versionamiento con Liquibase para migraciones y rollback.  
- Escalabilidad para manejar datos volumétricos (>100 registros).
