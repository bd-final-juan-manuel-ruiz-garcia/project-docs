# 💾 Modelo Físico de la Base de Datos

El modelo físico final de la base de datos se encuentra completamente implementado bajo el motor relacional **PostgreSQL**, estructurado y automatizado mediante archivos de migración XML administrados por **Liquibase**.

### Acceso a las Definiciones Físicas (DDL):
Toda la arquitectura física, restricciones de integridad, tipos de datos específicos, triggers y procedimientos almacenados pueden consultarse directamente en el repositorio de infraestructura técnica:

* 📄 [Scripts de Creación de Tablas (DDL) - project-bd](https://github.com/bd-final-juan-manuel-ruiz-garcia/project-bd/tree/main/project-bd/liquibase/ddl)
* 📄 [Diccionario de Datos Estructurado](08-diccionario-datos.md)
